## Intended architecture and invariants

Manifest https://spectre.guide/en/governed-act-model (fetch/read it); core docs/GAM.md, docs/MANAGED_GAM.md, docs/SKILLS.md, docs/AGENT_SERVER.md explain implementation. GAM kernel is a separate authority/consequence kernel. Classification/routing/cognitive model calls do not require user consent merely to infer intent. Registered governed effects enter automatic AgentServer GAM integration, exact material presentation, authenticated consumer acknowledgement and one-use consent when configured. Consent is not mandatory for every effect: trusted operation policy determines it. Application owns authenticated identity and business policies, not manual GAM protocol. Arbitrary trusted BEAM code is not sandboxed.

Stack installs tools/effects via existing Installable behaviour. Agent declares routes/classifiers/Skills. Server is real GenServer callback facade; helpers acquire durable commands; asynchronous results enter handle_result. Skill gets its own Server process/checkpoint/workers/assigns/pending state but shares root private Managed GAM/Domain. Root operation allowlist intersects mount restrictions. Proposal attribution records invocation Evidence. Topic changes/intent timers record lifecycle facts, never erase Duties. GAM laws unchanged.
